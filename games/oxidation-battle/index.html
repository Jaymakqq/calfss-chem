📘 氧化數規則（HKDSE 課本指引）

A. 元素狀態（單質）

自由單質分子中，原子的氧化數為零。

例子：S₈, O₂, P₄ 中原子均為 0
B. 單原子離子

單原子離子的氧化數等於其電荷數。

例子：Na⁺ = +1, Cl⁻ = -1, Fe³⁺ = +3
C. 鹼金屬與鹼土金屬

化合物中第 I 族金屬為 +1，第 II 族金屬為 +2。

D. 氟（F）

化合物中 F 的氧化數必為 -1。

E. 氫（H）與氧（O）

大部分化合物中 H 為 +1，O 為 -2。

⚠️ 特例：金屬氫化物 (NaH) 中 H 為 -1；過氧化物 (H₂O₂) 中 O 為 -1。
F／G. 化合物與多原子離子

中性化合物中各原子的氧化數總和為 0；多原子離子中各原子的氧化數總和等於離子電荷。

🟣 錯合物與錯離子觀念

中性配體（電荷 0）：H₂O = 0、NH₃ = 0、CO = 0

陰離子配體：Cl⁻ = -1、OH⁻ = -1、CN⁻ = -1、SCN⁻ = -1、C₂O₄²⁻ = -2

例子：[Co(H₂O)₄Cl₂]⁺ → x + 4(0) + 2(-1) = +1 → x = +3
